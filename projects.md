## 🗽 NYC 311 Complaints Data Pipeline & Dashboard
An end-to-end data pipeline that pulls live complaint data from the NYC Open Data API, stores it in a local database, and visualizes trends in an interactive Power BI dashboard.

**Stack:** Python · Requests · Pandas · SQLite · NYC Open Data API · Power BI

- Built a Python pipeline fetching 1,000+ live records from the NYC Open Data API using the Socrata endpoint
- Cleaned and transformed raw JSON data using Pandas and stored it in a normalized SQLite database
- Analyzed complaint trends by borough and type using SQL aggregates, GROUP BY, and filters
- Designed an interactive Power BI dashboard with cross-filtering slicers, bar charts, and pie chart breakdowns by borough and complaint category
